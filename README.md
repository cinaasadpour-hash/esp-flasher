# ESP Flasher | فلشر ESP

![Icon](icon.png)

[Download / دریافت برنامه](https://github.com/cinaasadpour-hash/esp-flasher/releases/latest)

## فارسی

نوشتن فریم‌ور بردهای پشتیبانی‌شدهٔ ESP با USB و استفاده از مانیتور سریال.

یک فایل فریم‌ور معتبر و آدرس صحیح آن را انتخاب کنید. برد باید به حالت دانلود وارد شود و کابل داده و OTG سازگار لازم است. فلش موفق روی همهٔ مدل‌ها تضمین نمی‌شود.

### تبلیغات

بنر استاندارد در صفحات عادی؛ هنگام عملیات فلش و در مانیتور سریال مخفی است.

نمایش تبلیغ به اینترنت و موجودی شبکهٔ تبلیغات بستگی دارد. امکانات اصلی به دریافت تبلیغ وابسته نیستند. تبلیغ بینابینی هنگام شروع برنامه نمایش داده نمی‌شود و تعداد نمایش آن محدود است.

## English

Flash supported ESP boards over USB and use the serial monitor.

Choose a valid firmware file and its correct flash address. The board must enter download mode; a compatible data cable and OTG adapter are required. Not every board or USB adapter is guaranteed to work.

### Advertising

Standard banner on ordinary pages, hidden during flashing and on the serial monitor.

Advertising requires an internet connection and available inventory. Core features do not depend on an ad being available. Interstitials are not shown on launch and are frequency-capped.

Package: `com.sinatools.espflasher` · Version: **1.0.2** · Minimum Android API: **24** · Target SDK: **36**.
